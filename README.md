# vibesketch

A vector design tool that runs entirely in your browser. No account, no server: your projects
stay on your computer.

**Open it: <https://avantiris.github.io/vibesketch/>** or run `nix run github:avantiris/vibesketch`.

Pick a tool, draw, and change the selected layer in the right panel. Drop files on the canvas to
import them. Everything is saved as you work. More in the [manual](docs/manual.md).
